## Key Architecture Decisions (Do Not Reverse)

1. **Pure pgx, no GORM** — GORM is being removed entirely; all queries use `pgxpool.Pool`
2. **Fresh network** — no existing data to migrate; `CREATE TABLE IF NOT EXISTS` is safe to run from scratch
3. **`InitSchema(ctx, pool)`** — single function in `core/wallet/schema.go` creates all 28 tables
4. **FOR UPDATE NOWAIT + sorted token IDs** — deadlock prevention strategy for multi-token writes
5. **`AtomicLedgerWriter.Write()`** — 4-table atomic commit (transactions + tokenchain + tokens + requests)
6. **`crypto.Seal()` uses argon2id** — already implemented in `crypto/seal.go`, all private key storage should use this
